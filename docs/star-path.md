# 把光带到一起：完整星路

主线已经从接光开场贯通到手链与生日回信。玩家始终带着同一颗主星和三个愿望，发现的颜色、日期与长短回应都在后面的世界里留下作用。

## 接光与自由探索

`GuidingLight` 让玩家把近处的光带到远方回应；拖动、轻触远方或键盘都能接通。选定三个愿望后，它们成为主星身边的伴星，再由玩家接光出发。

棱镜与生日星盘可任意顺序探索，也可以返回重访。粉色附近稳定停留 600 ms 后，光舒展开，主星带走粉色；十月八日对齐后，两枚星盘汇光并留下宝石的位置。两项发现齐备，才能把粉光送入宝石线框。入石保留形状、位置与生日星轨，减少动态效果时使用更短的淡入。

## 宝石里的三个发现

旋转宝石，让切面、天秤星图与粉光依次在三个真实角度附近对齐。每次需要停止转动并稳定停留 880 ms，两条发现之间留有阅读时间；累计拖动距离不会解锁含义。指针取消或失焦会撤销未完成的拖动。

已发现的名字、天秤与粉色持续留下。全部找到后出现出口粉光，由玩家轻触继续，进入愿望摩斯接力。

## 两岸逐渐学会回应

三段星路始终显示，已接通路段不会消失；每次送达时，主星沿该段移动到下一站。

- **W**：远方先完整示范 `.--`，玩家完整回应一短两长。
- **2**：来信发出两束短光后变模糊。玩家点击任意同行愿望星帮助恢复，听完余下三束长光，再回应完整 `..---`；已经送达的愿望也能帮助。
- **5**：按“远方、玩家、远方、玩家、远方”轮流完成 `.....`。远方回声会实际发亮，等待期间连点不能替代它的回合。

愿望保留在场景中，送达顺序由玩家选择。勇气、幸运、爱、明天提供开头提示；平静、归属延长来信；惊喜、好奇显示下一束轮廓。效果可组合，但不会自动填入玩家应当回应的节奏。错误保留正确前缀，支持重听、至少一秒长按、键盘和短/长辅助按钮。这是单人两岸配合，没有联网双人模式。

## 星路在真实手链上闭合

`PathClosure` 展开走过的光路，玩家把主星送到最后一个星点，也可点击终点或用键盘接通。光路闭合后，真实 GLB 的 13 个长短链节按 W、2、5 顺序点亮；每根长链节的三颗钻石共同表示一划。点位来自现有模型，加载后热点随模型投影；加载过程中提供对应的后备图点位。

揭晓完成后可再次选择三组节奏查看对应链节。场景保持停留，必须点击“让它来到眼前”，才进入可旋转的完整手链与 AR Quick Look。

手链旁写着“把目光从屏幕移开。最后一束光，正等着来到你手里。”玩家点击“礼物已在身边，读完这封信”或触碰粉色宝石，手链化为星光并进入 Project W25 与 HBD, Leah。这里没有强制交付倒计时。本轮未修改 GLB 二进制、几何和材质。

## 保存与重访

仍使用 version 2 存档。`Journey.path` 保存探索位置、颜色、日期与入石状态；可选 `echoWishes` 保存愿望送达顺序；可选 `pathClosed` 保存闭环揭晓是否已完成。旧第二至第四章迁移到共享星路，保留已有发现；旧后半程保持进度，没有 `pathClosed` 的第六章先展示闭环。

完成后可以直接看手链与 AR、重读生日回信、重温之前的愿望或选择新的愿望。重温和新旅程清空本轮探索，通关历史保留。声音偏好在当前设备单独记忆。

## 核验边界

规则与真实 React 场景测试覆盖发现前置条件、角度停留、三轮摩斯、闭环主动继续、旧存档与重访，以及取消触摸、帮助暂停、切后台和卸载时钟清理。模型检查核对链节名称、真实点位与 W25 分组。

390px 浏览器已从新开场完整走到 HBD, Leah；宝石与闭环画面已检查 320、390、1440px，模型非空、热点对齐且没有横向溢出；减少动态、声音记忆与重访刷新也已复核。浏览器与静态模型检查不能替代 iPhone 真机测试；触控手感、流畅度和系统 AR 的真机结果尚未确认。
