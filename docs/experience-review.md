# 星间来信：体验收尾

这是一封写给 Leah 的纪念来信。每一段都要让上一段留下的东西继续发挥作用：愿望随身，颜色被记住，生日化作宝石，长短的光把愿望送达，最后在手链上相遇。

## 文字与引导

借鉴《纪念碑谷》带来的短句与留白感，全部使用原创文字。每句话只说一件事，先让人知道在做什么，再留一点余韵。避免“接通这一组”“正确答案”“进度”等系统措辞，也避免只写晦涩的诗句。

动作发生的地方保留简短动词：拖动、转动、轻按、长按。完整操作、时长和替代输入放在帮助或展开提示中。声音开关、保存失败、模型重试、AR 兼容说明保留清楚的功能文字，防止为了诗意而让人无法操作。

例如：开场“想带走的，留在心里”；转动前“轻轻转动，看看光里藏着什么”；答错后“没关系。已经点亮的光，还在等你”。它们分别承担愿望、探索与安抚的作用。

## 七段之间的情感推进

| 段落 | 玩家留下的东西 | 如何带到下一段 |
| --- | --- | --- |
| 三个愿望 | 自己选择的未来 | 三句对应祝福之后，“再借一束你喜欢的光” |
| 色散 | 最爱的粉色 | 原有无文字的色散交互保持；光散开后才浮现一句回忆，接向星轨 |
| 星轨 | 一瞬与停留的区别 | 唤醒 W，余光接续；“有些光，记得你来时的日子”引入星盘 |
| 生日与宝石 | 十月八日、天秤、粉色蓝宝石 | 实际两枚星盘旋转汇光，再化作星点线框；转动逐渐读出含义；离开时想起还要带上三个愿望 |
| 回声 | 把愿望送过星海 | 愿望带来帮助；短长回应逐步读出 W25；正确信号自行渡海，无额外确认 |
| 手链 | 所有元素相遇 | 保留完整环形模型、垂落尾饰与 AR；模型淡为星点形体后再散入天空 |
| 生日回信 | 回到最初的选择 | Project W25 停留后变成 HBD, Leah；最后写出玩家的三个愿望 |

蓝宝石是为她选择的专属诞生纪念，文字不把它说成十月或天秤唯一、统一的诞生石。生日仍是十月八日，最爱的颜色仍是 #ffb3de。

## 五款游戏如何留下痕迹

以下是本作的设计借鉴，不复刻角色、素材、界面或台词。

| 参考 | 借鉴的重点与来源 | 本版落点 |
| --- | --- | --- |
| 《底特律：化身为人》 | 选择影响后续体验。[官方介绍](https://www.quanticdream.com/en/detroit-become-human) | 开场三个愿望决定可用的帮助和最终祝福；摩斯中选择先送哪个愿望，又影响后续得到帮助的顺序 |
| 《小丑牌》 | 持有的牌改变规则，效果互相组合。[发行商介绍](https://www.playstack.com/games/balatro/) | 三个愿望构成一手光：勇气/幸运/爱/明天捎去开头的光，平静/归属放慢来信，惊喜/好奇留下下一束光的轮廓。送达的愿望继续同行，帮助叠加；始终至少留一束需要玩家回应 |
| 《Sheepy》 | 小小的主角在安静的世界里探索。[创作者页面](https://mrsuicidesheep.itch.io/sheepy) | 光承担引路角色，先闪动再等待触碰；只需唤醒 W，其他星光自行接续。保留安静色散、细流星和连续背景，减少文字对探索的打断 |
| 《死亡搁浅》 | 通过送达建立联系。[PlayStation 开发团队介绍](https://blog.playstation.com/?p=214960) | 送出的内容是她自己选的愿望；回应让两端之间的路径逐渐亮起，送达后对岸继续为下一程照路 |
| 《双影奇镜》 | 两方通过行动与时机配合前行。[官方介绍](https://www.ea.com/en/games/split-fiction/split-fiction) | 一端发出长短光，另一端回应；愿望能代送开头，第二程交换两岸位置，已送达的光帮助尚未出发的光。这是单人双端接力的借鉴，没有增加真正双人联机模式 |

## 测试重点

新增规则测试覆盖三愿望组合、不同发送顺序、错误保留、禁止重复送达、旧存档恢复。真实 React 场景测试覆盖帮助暂停、切后台、长按失焦取消、自动送达仅触发一次以及卸载清理动画计时。

本轮未改动手链几何、AR 链接结构、棱镜绘制或结尾保持时间。类型检查与静态构建之外，仍需要用 iPhone 真机判断整体节奏、触控手感和排版。
