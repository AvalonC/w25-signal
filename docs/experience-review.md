# 星间来信：体验收尾

当前主线已从接光、愿望、自由探索贯通到摩斯接力、星路闭环、现实交付与生日回信。具体状态和保存规则见 [完整星路](star-path.md)。

这是一封写给 Leah 的纪念来信。上一段留下的东西在下一段继续发挥作用：愿望随身，颜色被记住，生日留下宝石，回应接通星路，最后看见这些长短的光原来就在手链上。

## 文字与动作

文字短而直接，每句话先让人知道在做什么，再留一点余韵。操作发生的位置保留简短动词，详细说明与替代输入放进帮助；声音、保存失败、模型重试和 AR 兼容信息使用清楚的功能文字。

每段的关键出口由玩家触发：接光出发，选择愿望后带光前行，宝石发现后触碰粉光，星路闭合后点击“让它来到眼前”，现实交付后继续读信。摩斯三段回应完成后，主星自动带着伴星继续前行，把 W25 留到手链闭环时揭晓。手链揭晓动画保留观看时间，完成后允许停留，再由玩家决定何时把礼物带到眼前。

## 五款游戏的设计借鉴

以下是交互原则的借鉴，不复刻角色、素材、界面或台词。

| 参考 | 借鉴重点 | 当前落点 |
| --- | --- | --- |
| 《底特律：化身为人》 | 选择影响后续体验 | 三个愿望改变帮助方式与最终祝福，送达顺序影响后续可组合的帮助 |
| 《小丑牌》 | 持有效果互相组合 | 开头提示、慢速来信和轮廓提示组合生效；效果不替玩家跳过应回应的节奏 |
| 《Sheepy》 | 小主角在安静世界里探索 | 同一束主星承担动作，玩家自由探索、携带发现，文字与出口依附场景 |
| 《死亡搁浅》 | 送达建立联系 | 愿望帮助另一岸恢复，已修复路径持续存在，送达后主星前移 |
| 《双影奇镜》 | 双方通过行动与时机配合 | W 学会模仿，2 主动援助，5 轮流接力；远方自动回声清楚可见，玩家无法连点代替其回合 |

两岸接力为单人体验中的协作角色，不是联网双人游戏。最后的闭环使用现有 GLB 中真实的链节位置；三钻长链节是一划，点状链节是一点。本轮未修改模型二进制或几何。

## 验证范围

测试覆盖选择与存档、自由探索、角度停留、三轮摩斯、错误保留、暂停与取消、真实链节映射、闭环主动继续和通关重访。`pathClosed` 是 version 2 的可选字段，兼容旧记录；重玩会重置本轮过程。

390px 浏览器已完整走到生日回信，宝石与闭环画面已检查 320、390、1440px，未见横向溢出或脚本错误。未声称完成 iPhone 真机测试；触控手感、真实设备流畅度、振动反馈与系统 AR 需要在对应设备确认。
