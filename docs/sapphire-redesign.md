# 粉色蓝宝石：星光凝成宝石

已实现，日期以 10 月 8 日为准。本环节由细星点汇聚成四角星轮廓的宝石线框，切面随拖动旋转，不再直接展示手链中提取的实物宝石。完整手链模型仍在最后一章呈现。

1. **星点汇聚。** 日期确认后，散落星点用 3.2 秒收拢；切面细线逐渐显现。
2. **用动作示意。** 线框轻轻左右转动，伴随双向箭头和“左右转动它，点亮三个切面”。
3. **转动成为祝福。** 左右拖动约 55 像素，或轻触替代按钮，点亮一道祝福。每句从实际转动后停留至少 4.6 秒，再等待下一次转动。明确显示已点亮数量；切后台或打开提示时暂停。
4. **星光继续。** 三道祝福完成后，线框淡回星点，用统一的 1.8 秒离场节奏进入回声。

祝福文案：

- 愿你像蓝宝石一样，温柔，也坚韧。
- 愿你喜欢的粉色，照亮每一个平常的日子。
- 愿十月八日的星光，年年都为你而亮。

这一章使用轻量 Canvas 绘制，不需要下载宝石模型或启动模型查看器。减少动态效果时停用自动旋转示意和星点飞行，仍可用按钮完成流程。

实现入口：`components/game/sapphire-scene.tsx`、`components/game/star-sapphire.tsx`、`app/motion.css`、`lib/motion.ts`。以下为最后一章真实手链与保留的独立宝石资产导出说明。

`scripts/export-jewelry.py` 使用 Blender 从本地原始文件导出资产：

```sh
blender --background --python scripts/export-jewelry.py -- /path/to/silver_pink_bracelet_v3.blend /path/to/bracelet-ring.blend
```

第一个文件为原手链，第二个为已成环的完整 Blender 模型；省略第二个参数时读取本地 `work/bracelet-ring.blend`。源文件不随网页加载，仓库中的 GLB、USDZ 与后备图可直接使用。导出统一为米，不减面；完整手链含 288 个网格、141,478 个顶点和 144,520 个原始多边形，GLB 三角化后为 282,192 个三角形。独立宝石及镶座含 10 个网格、7,162 个三角形。
