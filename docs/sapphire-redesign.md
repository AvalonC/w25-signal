# 粉色蓝宝石：星光凝成宝石

已实现，日期以 10 月 8 日为准。本环节由细星点汇聚成四角星轮廓的宝石线框，切面随拖动旋转，不再直接展示手链中提取的实物宝石。完整手链模型仍在最后一章呈现。

1. **星盘汇光。** 两枚原有星盘继续旋转，用 3.8 秒收拢到同一光心。汇聚位置由真实布局测量，适应手机宽度。
2. **光化为星。** 光心用 1.8 秒散成细星点，再用 3 秒连成宝石线框，保持星点运动连续。
3. **转动是认识它的过程。** 连续转动或轻触替代按钮，依次显出蓝宝石的名字、天秤符号与生日记号、最爱的粉色。没有三次强制确认或三道祝福计数；已发现的含义留下轻量标签。每条新信息保留至少 4.8 秒，快速转动也不会跳过。
4. **含义汇成祝福。** 三层含义完整后，停留在“愿你一直拥有自己喜欢的颜色，也自在地成为自己”，然后用统一的 1.8 秒离场节奏进入回声。

发现文案：

- 蓝宝石：星光有了名字，也有了温柔而坚定的形状。
- 献给天秤座的你：为十月八日的你，选一颗专属的诞生石。
- 原来，它也可以是粉色：蓝宝石不只有蓝色。这一颗，是你最爱的粉色。

“诞生石”在这里表达送礼者的专属选择，不声称蓝宝石是统一的十月月份诞生石；[GIA 月份诞生石表](https://www.gia.edu/birthstones)将蓝宝石列于九月，十月为欧泊和碧玺。

这一章使用轻量 Canvas 绘制，不需要下载宝石模型或启动模型查看器。减少动态效果时停用自动旋转示意和星点飞行，仍可用按钮完成流程。

实现入口：`components/game/sapphire-scene.tsx`、`components/game/star-sapphire.tsx`、`app/motion.css`、`lib/sapphire-discovery.ts`。以下为最后一章真实手链与保留的独立宝石资产导出说明。

`scripts/export-jewelry.py` 使用 Blender 从本地原始文件导出资产：

```sh
blender --background --python scripts/export-jewelry.py -- /path/to/silver_pink_bracelet_v3.blend /path/to/bracelet-ring.blend
```

第一个文件为原手链，第二个为已成环的完整 Blender 模型；省略第二个参数时读取本地 `work/bracelet-ring.blend`。源文件不随网页加载，仓库中的 GLB、USDZ 与后备图可直接使用。导出统一为米，不减面；完整手链含 288 个网格、141,478 个顶点和 144,520 个原始多边形，GLB 三角化后为 282,192 个三角形。独立宝石及镶座含 10 个网格、7,162 个三角形。
